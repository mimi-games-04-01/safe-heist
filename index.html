SAFE #1

How to play

Crack the safe code: 6 digits, 6 tries. Digits in the code never repeat. After each try the cells light up:

7Right digit, right spot
3In the code, but in another spot
5Not in the code
Every wrong try adds a wanted star. Six stars and you’re busted.

You get only one heist, so make every try count. Crack the safe to win a bonus promo code.
